## Overview

The 8BitDo Signature is a special-edition variant of 8BitDo's mainstream leverless platform, built around a translucent purple shell and a Vxbao / Zhen collaboration colorway.

It swaps the standard switch set for Kailh Purple Glede low-profile switches while keeping the same compact, entry-level hardware package.

## Hardware

### Materials

**Top Panel**: Tempered glass (fingerprint-proof)

**Bottom Surface**: Silicone non-slip pad

**Feet**: Magnetic foldable metal feet

### Switch Configuration

**Stock Switch**: Kailh Purple Glede low-profile linear switches

Hot-swappable PCB - compatible with other low-profile switches.

## Compatibility

- **Firmware**: Proprietary 8BitDo firmware configurable through 8BitDo Ultimate Software V2
- **Native support**: Nintendo Switch, Switch 2, Windows
- **Connection**: Bluetooth + 2.4G wireless + wired USB-C
- **Notes**: Uses the same firmware and compatibility model as the standard 8BitDo All-Button Arcade Controller. Battery life is rated at about 20 hours.
