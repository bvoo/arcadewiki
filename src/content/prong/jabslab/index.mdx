## Overview

The Jabslab is Prong's compact slab-style controller for platform fighters.

It trades the wider GameCube-oriented footprint of larger rectangles for a smaller travel-friendly aluminum chassis with LED-heavy presentation, browser-based configuration, and a 12-button primary layout.

## Highlights

- Compact footprint
- 12 Kailh Choc Red Pro low-profile switches with polycarbonate caps
- Browser-based configuration and firmware updates
- Gyroscopic motion controls and per-button LED lighting

## Hardware

### Case and Materials

- **Case**: Aluminum chassis
- **Top layers**: Matte black top plus a separate clear top for artwork installation
- **Buttons / Keycaps**: Polycarbonate caps on the main inputs; 7 silicone rubber option buttons
- **Accessories fit**: Includes a controller sleeve, bottom grip pad, foam key dampeners, and hex keys for disassembly

### Switches

- **Stock switch**: Kailh Choc Red Pro
- **Type**: Low-profile linear mechanical switch
- **Adjustability**: Main settings, profiles, and lighting are configurable through the web interface

### Electronics

- **PCB / Controller**: Proprietary Prong controller electronics
- **Firmware / Software**: Proprietary firmware with a browser-based settings and update page
- **Special features**: 1000 Hz polling, gyroscopic motion controls, high-frequency per-button LEDs, and custom profile support

## Compatibility

- **Firmware**: Proprietary Prong firmware with web-based configuration and firmware updating
- **Native support**: Nintendo Switch, PC
- **Connection**: Wired USB-C
- **Notes**: The product page lists DInput, XInput, and keyboard modes.
