## Overview

The Hit Box Ultra is the final first-party evolution of the original Hit Box formula, replacing arcade buttons with keyboard switches and proprietary C.O.M.B.O. switches in a thinner steel-and-acrylic shell.

It keeps the brand's tournament-focused layout while moving closer to keyboard-style switch travel and easier service access.

## Hardware

### Materials

**Case**: Steel body with thick acrylic top

**Bottom Plate**: Magnetic removable bottom plate

**Bottom Surface**: No-slip bottom

### Switch Configuration

**Stock Switch**: Hit Box C.O.M.B.O. buttons

- Sensitivity: 0.3 mm
- Total travel: 1.0 mm (SUPER optimizer pre-installed)
- Adjustable with included optimizer sets: 0.65mm (ULTRA), 1.0mm (SUPER, default), 1.5mm (CLASSIC)
- Sound: Silent

**C.O.M.B.O. Extensions**: 3 square buttons (L3, R3, Touchpad) using Kailh PG1425 X switches

- Actuation: 1.5 mm travel; 2.0 mm total travel

**Included optimizer sets**: ULTRA (0.65mm), SUPER (1.0mm, pre-installed), CLASSIC (1.5mm)


### Physical Characteristics

The Hit Box Ultra uses a bezel-less design with a flush recessed cable port.

### Additional Features

- 4 SOCD modes: Natural / Last Input Priority / True Neutral / Hit Box Standard (L+R = Neutral, D+U = Up)
- Tournament lock switch
- Solder-free terminal block rewiring

## Compatibility

- **Firmware**: Proprietary Hit Box firmware (Uses a Brook PCB)
- **Native support**: PS5, PS4, Nintendo Switch, Switch 2, PC
- **Connection**: Wired detachable USB cable
