## Overview

The HORI NOLVA is a mainstream leverless built around accessibility and practicality rather than boutique material selection.

Its sloped wrist rest, rimless button layout, and split PC-only / PS5-capable SKUs give HORI a lower-cost entry in the commercial all-button market.

## Hardware

### Materials

**Case**: Lightweight plastic body

**Bottom Surface**: Non-slip rubber mat

### Switch Configuration

**Stock Switch**: Kailh Speed Silver

### Buttons

- Button diameter: 23mm (all action buttons); 26mm (jump button)
- Rimless button design
- Up to 15 buttons total (12 main + 3 removable expansion buttons)


### Additional Features

- Key lock switch
- Headphone/mic 3.5mm jack (PS5 version only)
- Touchpad (PS5 version only, not active on PC)
- Button removal tool on bottom of unit
- Companion app support for button remapping

## Compatibility

- **Firmware**: Proprietary HORI firmware configurable through the companion remapping software
- **Native support**: Windows 10/11 on the PC version; PS5 and Windows PC on the PlayStation version
- **Connection**: Wired USB-C to USB-A
- **Notes**: Uses a detachable ~3 m cable with a lock mechanism. The PS5 version adds PlayStation-specific controls such as touchpad and headset support.
