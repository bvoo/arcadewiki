## Overview

The Qanba Sapphire is a midrange licensed leverless that leans into configurability rather than a bare-bones tournament layout.

Its HUD, adjustable button travel settings, detachable wrist slope, and 18-button layout give it a more gadget-heavy feature set than many peers.

## Hardware

### Materials

**Bottom Surface**: Full rubber bottom

### Switch Configuration

**Stock Switch**: Cherry MX Speed Silver

- Mount: Hot-swappable
- Adjustable travel distance: Long / Medium / Short settings

**Button Sizes**: 24mm (standard), 30mm (jump button), 32mm (auxiliary)

**Total Buttons**: 18 customizable buttons


### Additional Features

- HUD screen for real-time button configuration display
- Integrated touchpad
- 5 RGB LED modes
- 3 saved profiles
- 3.5mm headset jack
- Detachable memory foam wrist slope
- SOCD cleaning
- Tournament lock switch
- PS5/PS4/PC mode switch
- Dual leverless/WASD layout support
- Customizable faceplate art

## Compatibility

- **Firmware**: Proprietary Qanba firmware with onboard profiles
- **Native support**: PS5, PS4, PC
- **Connection**: Wired detachable USB-C
- **Notes**: Official PlayStation licensing provides native console support. The onboard profile system and HUD screen are part of the controller's own firmware stack.
