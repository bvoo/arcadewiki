## Overview

The Victrix Pro KO is a slimmer, more customizable take on Victrix's premium tournament hardware.

Its hot-swappable Cherry MX Speed Silver switches, removable aluminum top plate, and EVO 2024 Best Tech Product award position it as a feature-heavy licensed PS5 leverless.

## Hardware

### Materials

**Top Plate**: Removable aluminum top plate

**Bottom Surface**: Rubber non-slip bottom

### Switch Configuration

**Stock Switch**: Cherry MX Speed Silver (RGB)

- Mount: Hot-swappable
- 16 moveable/mappable buttons


### Additional Features

- Ergonomic 6.28-degree wrist slope
- 3.5mm audio jack
- RGB lighting
- Tournament lock switch
- PS5/PS4/PC mode switch
- Button/cable organizers
- Protective sleeve included
- Victrix Control Hub software support (button remapping, profiles)

## Compatibility

- **Firmware**: Proprietary Victrix firmware configurable through Victrix Control Hub
- **Native support**: PS5, PS4, Windows 10/11
- **Connection**: Wired USB-C
- **Notes**: Official PlayStation licensing provides native console support without a passthrough auth chain. Uses Victrix Control Hub for remapping and profile management.
