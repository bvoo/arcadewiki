## Overview

AegisBox is CIELOGAMES' compact aluminum leverless, positioned closer to a low-profile Victrix Pro FS-12.

Its Gateron Low-Profile Kasumi Axis switches make it one of the more interesting options as far as leverless buttons go.

## Hardware

### Materials

**Case**: Full aluminum alloy body

**Bottom Surface**: Non-slip feet

### Switch Configuration

**Stock Switch**: Gateron Low-Profile Kasumi Axis (霞軸)

### Electronics

- **PCB / Controller**: RP2040-based PCB built around a Raspberry Pi Pico
- **Firmware / Software**: GP2040-CE
- **Special features**: Swappable and moddable PCB

## Compatibility

- **Firmware**: GP2040-CE
- **Native support**: PC, Nintendo Switch, PS4
- **Connection**: Wired USB
- **Notes**: PS5 support is limited because the board does not provide native PS5 authentication.
