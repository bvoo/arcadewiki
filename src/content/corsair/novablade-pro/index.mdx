## Overview

The Corsair NOVABLADE PRO is Corsair's first leverless controller, pairing Hall Effect switches with the feature set of a modern gaming keyboard.

Adjustable actuation, Rapid Trigger-style behavior, and tri-mode connectivity set it apart from more traditional tournament-first leverless designs.

## Hardware

### Switch Configuration

**Stock Switch**: Corsair MGX V2 Hyperdrive Hall Effect Magnetic Switches

- Actuation: Adjustable from 0.1 mm to 4.0 mm (in 0.1 mm steps)
- Rapid Trigger: Resets after as little as 0.1 mm lift
- Rated: 150 million presses
- Design: Double-rail, pre-lubricated, zero-wobble

### Electronics

- **PCB / Controller**: Proprietary Corsair controller electronics
- **Firmware / Software**: Proprietary Corsair firmware with onboard profile storage
- **Special features**: 8 MB onboard memory, 5 onboard profiles, and Hall Effect actuation tuning


### Physical Characteristics

The NOVABLADE PRO features a magnetic removable aluminum top plate, 360-degree RGB LightEdge, and a 2.4 GHz dongle stored under the magnetic plate.

## Compatibility

- **Firmware**: Proprietary Corsair firmware
- **Native support**: PS5, PS4, PC (Windows)
- **Connection**: Tri-mode wired USB + 2.4 GHz wireless + Bluetooth
- **Notes**: Supports up to 8,000 Hz polling. Uses a 7,500 mAh battery rated for about 40 hours with RGB on or 200 hours with RGB off.

## History

### Release History

The NOVABLADE PRO was announced on October 30, 2025 by Corsair, though teased through creators the months prior.
